# Home Thames · ESP32-C6 Mini (Wi-Fi Reconfigure v2.8)

> โค้ดนี้เป็น Firmware **Main Energy Meter (อ่านค่าเท่านั้น)** ไม่ใช้ตัดต่อไฟเมน

## สิ่งที่เพิ่มใน v2.8

- กดปุ่ม **BOOT บนบอร์ดค้าง 5 วินาที ในขณะบอร์ดเปิดและโปรแกรมทำงานตามปกติ** → ล้างเฉพาะ Wi-Fi เดิม → เปิดเครือข่ายตั้งค่า `HomeThames-Setup-XXXX` ของบอร์ด
- เชื่อมจากโทรศัพท์ → `http://192.168.4.1` → สแกนและเลือก Wi-Fi บ้านใหม่ (2.4 GHz) → กรอกรหัส → บันทึก
- หากบอร์ดเคยลงทะเบียน Home Thames แล้ว จะ **ไม่ถาม Setup Ticket ซ้ำ** และคง `device_id` กับ `device_token` เดิม รวมถึงข้อมูลย้อนหลังใน Cloud
- เครือข่ายเดิมหายไปเกินประมาณ 90 วินาที บอร์ดจะเปิด Wi-Fi ตั้งค่าอัตโนมัติ (ถ้าตั้งค่า AP ไว้แล้ว)
- เปิด Serial Monitor 115200 พิมพ์ `INFO` เพื่ออ่านชื่อและรหัสผ่านของ Wi-Fi ตั้งค่า
- `WIFI_SETUP` เปิดหน้าแก้ Wi-Fi โดยไม่ลบค่าของ Wi-Fi ปัจจุบัน, `WIFI_RESET` ลบเฉพาะ Wi-Fi, `RESET` ล้างค่า Wi-Fi และการจับคู่ (Factory Reset)

**สำคัญ:** รหัส Wi-Fi Setup เป็นรหัสสุ่มความยาว 14 ตัว สร้างเพียงครั้งเดียวและเก็บไว้ในหน่วยความจำบอร์ด ให้จดไว้หรือพิมพ์สติกเกอร์เก็บไว้ในที่ปลอดภัย จะได้เปลี่ยน Wi-Fi ที่บ้านอื่นโดยไม่ต้องต่อสาย USB อีก

## ครั้งแรกเมื่อบอร์ดยังไม่มี Firmware

1. ดาวน์โหลด ZIP เปิด `firmware/esp32c6-smarthome` ด้วย **VS Code + PlatformIO**
2. ตรวจรุ่นบอร์ดใน `platformio.ini` ให้ตรงกับบอร์ดจริง (ค่าปัจจุบันเป็น `esp32-c6-devkitc-1` ทดสอบแทน Waveshare Zero ได้บางรุ่นแต่ต้องตรวจ pinout/flash settings)
3. คัดลอก `include/secrets.example.h` เป็น `include/secrets.h`
4. ใส่ Project URL, Public Publishable Key และ **CA Certificate ที่ถูกต้องของ Cloud endpoint** ลงใน `secrets.h` ก่อนคอมไพล์ โดยห้ามใช้ Service Role Key หรือ `setInsecure()` (ตัวอย่างยังเป็น Placeholder และใช้แฟลชเชื่อม Cloud จริงไม่ได้ถ้ายังไม่ตั้งค่า)
5. เสียบ USB-C → VS Code กด **PlatformIO: Upload** และเปิด Serial Monitor 115200
6. เปิดเว็บ Home Thames → สร้างบ้าน → เพิ่มอุปกรณ์ → มิเตอร์หลัก → คัดลอก Setup Ticket อายุ 15 นาที
7. Serial Monitor จะแสดง `SETUP AP`, `SETUP PASSWORD` และ URL `192.168.4.1`
8. โทรศัพท์เชื่อมต่อ Wi-Fi บอร์ด กรอก Wi-Fi บ้าน 2.4 GHz และ Setup Ticket 48 ตัวอักษร → บันทึก
9. เมื่อได้ Pairing Code 16 ตัว ใส่กลับที่หน้า Home Thames เพื่อจับคู่

## เมื่อต้องการย้ายไป Wi-Fi ใหม่

1. จ่ายไฟให้ ESP32 ทำงานตามปกติ (อย่ากด BOOT ตอนกด RESET หรือเสียบไฟ)
2. กด **BOOT ค้าง 5 วินาที แล้วปล่อย** เพื่อเปิด AP ตั้งค่า (หรือหาก USB ยังต่ออยู่ พิมพ์ `WIFI_RESET` แล้ว Enter ใน Serial Monitor)
3. โทรศัพท์เลือกเครือข่าย `HomeThames-Setup-XXXX` แล้วกรอกรหัสที่เคยจดไว้
4. เปิด `http://192.168.4.1` → กดสแกน → เลือก Wi-Fi 2.4 GHz ใหม่ → ใส่รหัสผ่าน → บันทึก
5. เมื่อ ESP32 เชื่อมต่อ Wi-Fi และ Cloud ได้ จะอัปเดตสถานะเป็นออนไลน์โดย **ไม่ต้องเพิ่มมิเตอร์ใหม่**

> ปุ่ม BOOT บน ESP32-C6-Zero เชื่อมกับ GPIO9 (bootstrapping pin) อย่ากด BOOT ค้างระหว่างรีเซ็ต/เปิดบอร์ด เพราะอาจเข้าระบบดาวน์โหลดโปรแกรมแทน

## RESET ต่างกันอย่างไร

- `WIFI_RESET` / BOOT ค้าง 5s: ล้างเฉพาะ Wi-Fi บ้าน **ไม่ล้าง Cloud Pairing**
- `WIFI_SETUP`: เปิด AP ตั้งค่าโดย **ไม่ล้าง** Wi-Fi ปัจจุบัน
- `RESET` ผ่าน Serial: **Factory Reset** ล้างการจับคู่ด้วย ต้องลบอุปกรณ์จากเว็บ Home Thames ก่อนเริ่มลงทะเบียนใหม่เพื่อไม่ชน Hardware ID เดิม

## ข้อควรระวัง

- ปุ่ม BOOT เป็นปุ่มฮาร์ดแวร์ที่ต้องกดได้จริง ถ้าบอร์ดอยู่ในตู้ไฟที่ล็อกอยู่ อย่าเปิดตู้หรือสัมผัสอุปกรณ์ไฟบ้านเพื่อกดปุ่ม ให้ช่างไฟฟ้าจัดจุดเข้าถึงอย่างปลอดภัย
- ทดสอบ Wi-Fi ผ่าน USB เท่านั้นก่อนต่อวงจร PZEM-004T ส่วนไฟบ้านมีความเสี่ยงสูงและต้องติดตั้งโดยช่างไฟฟ้าที่มีคุณสมบัติเหมาะสม
- ยังไม่ได้คอมไพล์ Firmware กับบอร์ด Waveshare ของคุณจริงหรือทดสอบ End-to-End จนกว่าคุณจะ Upload และเช็ก Serial Monitor
