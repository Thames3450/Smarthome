# Firmware ESP32-C6 + PZEM-004T (วัดไฟเมนอย่างเดียว)

1. เปิดโฟลเดอร์นี้ใน VS Code + PlatformIO และตรวจรุ่นบอร์ดตาม `platformio.ini`
2. สำเนา `include/secrets.example.h` เป็น `include/secrets.h` แล้วใส่ URL ของ Supabase, Publishable Key และ CA Certificate ที่ถูกต้อง
3. ต่อเฉพาะวงจรไฟแรงดันต่ำตาม datasheet โดยมีอุปกรณ์แยกสัญญาณที่เหมาะสม; งานติดตั้ง PZEM ที่ตู้เมนต้องให้ช่างไฟฟ้าที่มีคุณสมบัติเหมาะสมดำเนินการ
4. ในเว็บ Home Thames: สร้างบ้าน → เพิ่มอุปกรณ์ → มิเตอร์หลัก → คัดลอก Setup Ticket อายุ 15 นาที
5. ต่อ USB และเปิด Serial Monitor 115200 เพื่ออ่านชื่อ SSID / รหัสผ่าน Wi-Fi Setup ของ ESP32
6. โทรศัพท์เชื่อม `HomeThames-Setup-XXXX` แล้วเปิด `http://192.168.4.1`; กรอก Wi-Fi บ้าน 2.4 GHz และ **Setup Ticket 48 ตัว**
7. บอร์ดเชื่อมอินเทอร์เน็ตและลงทะเบียน แล้วแสดง Pairing Code 16 ตัวในหน้าตั้งค่าหรือ Serial
8. กลับเว็บ Home Thames ใส่ Pairing Code เลือกห้องและตั้งชื่อ → ระบบเริ่มรับค่าทุกประมาณ 10 วินาที บันทึกฐานข้อมูลทุกประมาณ 60 วินาที

หากลบอุปกรณ์ออกจากเว็บหรือจำเป็นต้องตั้งใหม่: **ต่อ USB** เปิด Serial Monitor 115200 พิมพ์ `RESET` และกด Enter เพื่อเคลียร์ Wi-Fi และ Device Token ในบอร์ด (เก็บบอร์ดไว้ต่อหน้าคุณขณะรีเซ็ต) จากนั้นเริ่มขั้นตอนใหม่

**ห้าม** ใช้โปรเจกต์นี้สำหรับสั่งเปิด/ปิดไฟเมน. ไม่มีวงจรตัดต่อไฟฟ้า และเฟิร์มแวร์ปิดฟังก์ชันรีเลย์โดยเด็ดขาด
